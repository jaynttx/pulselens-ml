UNDERSTAND WHAT YOU BUILD

Behind the science.

Two approaches. One tiny change in reflected light.

How does a camera see your pulse?

Blood volume changes with each heartbeat, creating subtle changes in reflected light from facial skin. Remote photoplethysmography (rPPG) estimates the repetition rate of these changes.

The classical path

Face detection → cheek and forehead colour traces → overlapping POS windows → detrending → spectral and autocorrelation analysis → quality gating → BPM.

The learned path

A 36 × 36 RGB face crop enters the pretrained FacePhys state-space model. Its hidden state is updated with each frame. The predicted pulse is analysed over a rolling time window to estimate BPM.

What is our contribution?

New frontend, camera/session lifecycle, original POS and spectral implementation, a new inference adapter, quality checks, paired benchmark tools, automated signal tests, and project documentation.

FacePhys model weights are pretrained third-party assets; we do not claim to have trained them. The original PulseLens repository inspired this comparison.

Be honest about uncertainty

Motion, illumination, camera frame timing, skin appearance, and model training-domain differences affect estimates. Spectral concentration is a heuristic quality score, not a probability of medical accuracy.
